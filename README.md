\# Vivid Sound



A Minecraft mod that brings more detailed and immersive sound effects to your world.

\## Requirements



\- Minecraft 1.21.1

\- Fabric Loader 0.20.1

\- Fabric API 0.116.18+



\## Installation



1\. Install \[Fabric Loader](https://fabricmc.net/use/) for Minecraft 1.21.1

2\. Download and place Fabric API jar into your `mods` folder

3\. Place the built `VividSound-\*.jar` into your `mods` folder

4\. Launch the game with the Fabric profile
